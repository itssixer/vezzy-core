# Vision

Vezzy is a place to learn by shipping.

The first surface is a page in the browser. You write HTML, CSS, and JavaScript, run it, and see it. The loop is short on purpose. A broken preview is the lesson, not a slide.

The public core exists so that loop, and the UI that frames it, can be inspected without opening the hosted product. Themes, layout frames, and the client-side runner are the identity of the workspace. They belong in the open.

What we are not doing in this repository:

- Turning the workspace into a generic cloud IDE for every language on day one
- Hiding the run loop behind a proprietary compiler for HTML/CSS/JS
- Publishing account systems, edge orchestration, or backup pipelines

Hello World is the start. Live architecture is the aim. The open core is the floor you stand on while you get there.
